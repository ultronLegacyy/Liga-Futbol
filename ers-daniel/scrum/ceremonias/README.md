# Eventos Scrum

Un archivo por evento: `AAAA-MM-DD_<evento>[_sprint-NN].md`, donde `<evento>` es `planning`, `daily`, `review`, `retro` o `refinamiento`. Ejemplo: `2026-10-20_planning_sprint-01.md`.

Los mantiene el agente `scrum-master` con lo que el equipo reporta. Nada se registra como hecho si nadie lo reportó.

Plantilla:

```
# <Evento> · AAAA-MM-DD · Sprint NN

- Asistentes (roles):
- Time-box:

## Agenda

## Lo que reportó el equipo

## Acuerdos

## Acciones

| Acción | Responsable (rol) | Fecha límite |
|---|---|---|

## Impedimentos nuevos
```
